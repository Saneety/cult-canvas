## Name

Cult Canvas

## Short description

The directory takes it from `manifest.json`; if the form asks for it, paste the same text:

Turn canvases into a whiteboard: sticky notes, shapes, a freehand marker, frames, layers, a minimap and a context menu. Needs Advanced Canvas.

## Long description

Turn Obsidian canvases into a whiteboard. A left toolbar with one-key tools: sticky notes, borderless text, flowchart shapes, a freehand marker and eraser, frames and a minimap. Alt+drag copies, a right-click menu changes layers, and each element remembers your last style. Boards stay plain .canvas files with working [[links]], so scripts and AI agents can edit them too. Needs Advanced Canvas.
